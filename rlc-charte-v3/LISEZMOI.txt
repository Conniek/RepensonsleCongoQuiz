CHARTE v3 - cette fois elle s'applique partout
==============================================

    cp -R chemin/vers/rlc-charte-v3/. .
    rm -rf .next && npm run dev
    npx tsc --noEmit

POURQUOI RIEN NE CHANGEAIT

  La charte n'etait posee que sur les jetons Tailwind (--fig-*). Or les
  ecrans de l'application ne lisent pas ces jetons : ils lisent --fond,
  --encre, --bleu, --ocre, definis dans jetons.css et utilises par
  habillage.css. Ces valeurs-la etaient restees creme et bleu.

  Cette fois, ce sont les jetons DE BASE qui portent la charte. Les NOMS ne
  changent pas, donc habillage.css et tous les ecrans deja ecrits suivent
  sans une ligne de plus :

      --fond            #FAF7F0 creme   ->  #FFD700 jaune
      --surface         #FFFFFF blanc   ->  #FFF4C7 creme
      --encre           #1A1614         ->  #15151B
      --bleu            #17497C         ->  #2D5BB9 bleu roi
      --ocre            #E3A72F         ->  #F1C627
      --rouge/terre     ...             ->  #CE2947
      --vert            #2F5D45         ->  #08745B
      --police-titre    system-ui       ->  Poppins

AUTRES CORRECTIONS

  - « +undefined points d'experience » sur le defi du jour : la RPC renvoie
    recompense_xp, l'ecran lisait xp_bonus.
  - Le splash avait sa propre palette, anterieure a la charte (bleu nuit,
    photo du fleuve sous un voile bleu). Il lit maintenant les jetons.
  - ThEME SOMBRE RETIRE. La charte est jaune et encre ; une inversion
    automatique produisait une application qui ne lui ressemblait plus.
    color-scheme passe a light, pour que le navigateur n'inverse pas non
    plus les champs de formulaire. C'etait la carte T6 du backlog : elle est
    tranchee, dis-moi si tu preferes l'inverse.
